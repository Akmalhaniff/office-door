# Office Door

A tiny one-button web app that triggers the office access door via `access.tiketbas.my`.

- No credentials are stored in this repo. On first launch, enter your username, key and token; they are kept in the browser's localStorage on that device only.
- Shortcut: open the app once with `?username=...&key=...&token=...` appended — the values are saved locally and removed from the address bar.
- On iPhone: open the page in Safari → Share → **Add to Home Screen** for a one-tap app.
